### 🎵 **YoYTMusic API** — YouTube Music Serverless Wrapper
**[Repository](https://github.com/Shubhamnpk/yoytmusic-api) | [API Docs](https://shubhamnpk.github.io/yoytmusic-api/)**

A professional, serverless HTTP wrapper for the powerful `ytmusicapi` library. Built specifically for Vercel, it transforms a complex Python library into clean, CORS-ready JSON endpoints—perfect for frontend applications.

- **Tech Stack:** Python (52%), HTML/JavaScript (48%)
- **Key Features:**
  - Zero-config Vercel deployment
  - Public YouTube Music catalog search
  - 15+ generic method endpoints
  - Full CORS support for frontend use
  - Interactive API playground & OpenAPI documentation
- **License:** MIT
- **Topics:** API, Python, YouTube Music
